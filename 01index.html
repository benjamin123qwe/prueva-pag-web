INTRODUCCIÓN A CSS3

Cascading style Structure (Estructura de estilos en cascada).
Permite definir la presentación visual de un documento HTML.

HTML es el esqueleto que tiene una casa, CSS es la pintura, la decoración y dispocición
de los muebles. Para entender esta analogía correctamente vamos a desglosarla por niveles

Los Fundamentos

  1. Que es la sintaxis de CSS?
    Se enfoca en reglas. Una regla le indica al navegador. "Busca este elemento de HTML y cámbiale estas características."

    La estructura básica es:

    • Selector:El elemento HTML que vas a afectar.
    • Declaración:La declaración va entre () y contiene la propiedad y el valor.
    • Propiedad:El atributo que se desea cambiar (el. Color, Fuente)
    • Valor:El ajuste específico (ej. red, arial, 30px)

  2. Como se conectan CSS a HTML?
    Existen 3 formas de aplicar estilos: externa, interna y de línea.
    La externa es la que se usa en proyectos reales por su orden y eficiencia.

    1. Estilos externos: Se crea un archivo separado llamado estilo.css y se lo vincula en el head.
    2. Estilos internos: Se usa la etiqueta style dentro del head.
    3. Estilos de línea: Se usa el atributo style en la etiqueta HTML, funciona pero no es recomendable.

  3. El modelo caja
    Es el concepto más importante de CSS. Para el navegador, todo en una página web es una caja rectangular.

    Cada caja tiene 4 partes:

    • Contend: El texto o imagen real.
    • Padding: El espacio es transparente alrededor del contenido.
    • Border: Una línea que rodea el relleno y contenido.
    • Margin: El espacio exterior que separa esta caja de otras cajas.
